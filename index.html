Ammonites : Home Page

Description

Extinct Marine Mullusk
Shell = almost perfect spiral
Shell = light on bottom dark on top
90 tentacles
Very primitive eyes
More related to octopi and squid than Nautilidae
Diet consisted of:

  • Zooplankton
  • Crustaceans
  • Other Ammonoids
Died out during the Cretaceous–Paleogene extinction event
Many different shaped shells to find best shape for evolutionary advantage
Index fossil (I own one)
